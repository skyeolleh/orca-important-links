# 중요 링크 — Orca 플러그인

Orca의 우측 패널에서 **현재 세션 / 글로벌** 링크를 나눠 관리합니다. 현재 배포 버전은 **0.3.2**이며 Orca **1.4.222 이상**이 필요합니다.

상단에는 제목과 메뉴만 남겼습니다. 각 영역의 `+`로 주소를 추가하고, 현재 세션의 별표를 누르면 글로벌에도 등록됩니다. 두 영역의 삭제와 되돌리기는 독립적으로 동작합니다.

## Orca 메뉴에서 설치

1. **설정 → 플러그인 → 소스 관리**를 엽니다.
2. 다음 값을 입력하고 **소스 추가**를 누릅니다.

   | 항목 | 값 |
   | --- | --- |
   | Git URL | `https://github.com/skyeolleh/orca-important-links.git` |
   | Git ref | `main` |

3. 기존 로컬 설치본 **중요 링크 0.1.0 / 0.3.x**가 있으면 필요한 목록을 먼저 백업하고 제거합니다. 이름이 같은 로컬 설치본이 남아 있으면 저장소 목록의 설치 버튼이 나오지 않을 수 있습니다.
4. 플러그인 목록의 **All**에서 `session-links` 또는 중요 링크를 찾아 **설치**를 누릅니다. 마켓플레이스 카드의 이름은 Orca 버전에 따라 플러그인 ID로 표시될 수 있습니다.
5. 설치 검토를 마치고 **활성화**, 우측 **중요 링크** 패널을 엽니다. 기존 JSON 백업은 패널 메뉴에서 가져올 수 있습니다.

**업데이트를 쓰려면 소스 관리에 등록한 마켓플레이스를 통해 설치해야 합니다.** 상단의 일반 플러그인 설치에서 Git URL만 입력하면 Git 직접 설치가 되어 마켓플레이스의 업데이트 버튼 대상이 아닙니다.

## 버전을 지정해 직접 설치

상단 **플러그인 설치 → Git 저장소**의 한 줄 입력란에는 다음처럼 입력합니다.

```text
https://github.com/skyeolleh/orca-important-links.git#0.3.2
```

`#0.3.2`는 저장소의 실제 Git 태그입니다. 버전 번호 대신 `#main`을 사용하면 설치 시점의 main 브랜치를 받습니다. 매니페스트의 버전 숫자만으로 Git 태그가 자동 생성되지는 않습니다.

이 방식은 직접 Git 설치이므로 마켓플레이스의 업데이트 확인 버튼이 연결되지 않습니다. 메뉴에서 업데이트하려면 위의 **소스 관리 → Git URL과 Git ref를 각각 입력 → All에서 설치** 절차를 사용합니다. 이때 마켓플레이스의 Git ref는 `main`을 권장합니다.

## 업데이트

이후 새 버전은 같은 저장소의 `main`에 배포됩니다. **설정 → 플러그인 → 새로고침 → All → 해당 플러그인의 업데이트 확인**을 누르고 변경 내용을 검토한 다음 업데이트를 적용합니다. 현재 Orca의 업데이트 버튼은 마켓플레이스 카드에 있으며 Installed 카드의 `…` 메뉴에는 없습니다.

이미 설치한 버전과 내용이 같으면 업데이트가 없다는 안내가 나옵니다. 새로운 파일은 Orca에서 다시 검토·활성화를 요구할 수 있습니다. 현재 열린 패널의 목록은 임시 보관이므로 업데이트 전에 필요한 자료를 백업합니다.

## 지원 범위와 제한

- 현재 세션 영역은 메뉴에서 직접 선택한 작업 묶음입니다. **실제 Codex 세션 자동 추적과 대화의 링크 자동 수집은 미구현**입니다.
- 글로벌은 열린 패널 안의 모든 작업 묶음에서 공유합니다. **영구 저장은 미구현**이며 패널 재생성·재시작 시 목록이 사라질 수 있습니다. 메뉴에서 백업 JSON을 복사·가져올 수 있습니다.
- **패널에서 외부 링크 직접 열기는 현재 Orca API가 제공하지 않습니다.** 카드를 누르면 주소 확인·복사 창이 열립니다. 복사가 허용되지 않으면 선택한 주소를 Ctrl+C 또는 macOS의 ⌘C로 복사해 브라우저·파일 탐색기에 붙여 넣습니다.
- 같은 주소는 각 영역 안에서 중복 없이 관리합니다. 현재 세션과 글로벌에 각각 등록하는 것은 가능합니다.
- 별도의 앱 패치, 터미널 명령 주입, 네트워크 접근, 외부 패키지 설치는 필요 없습니다.

## 개발과 배포

설치용 `orca-plugin.json`, `panel.html`과 마켓플레이스 목록 `orca-marketplace.json`이 저장소 최상위에 있습니다. 설치 시 빌드나 npm 설치를 하지 않습니다.

소스는 `src/`에 있습니다. Node 22 이상에서 외부 의존성 없이 다음 명령을 실행합니다.

```powershell
node build.mjs
node --test test/*.test.mjs
```

새 버전 배포 시 플러그인 매니페스트와 `package.json`의 버전을 올리고 패널을 다시 생성·검사한 뒤 `main`에 반영합니다. 마켓플레이스 소스는 `main`을 추적하며 Orca가 실제 설치 내용과 커밋을 기록합니다. 이미 사용 중인 이전 커밋이나 태그를 강제로 덮어쓰지 않습니다.

## 검증

0.3.2의 설치 구조와 DOM 기반 상호작용 검사 19개가 통과했습니다. 실제 Orca의 설치 화면·렌더·클립보드·업데이트 적용은 아직 수동 검증하지 않았습니다. 저장소 검사와 실제 앱 동작을 구분합니다.
